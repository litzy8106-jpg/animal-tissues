# BIO 110 Tissues & Organ Systems Review

Interactive study site for BIO 110: animal tissues plus the integumentary, nervous, digestive and respiratory systems, built for the tissue-identification moving exam.

**Live site:** https://YOUR-USERNAME.github.io/YOUR-REPO/

## What's inside
- **Learn**: big-picture concept map; epithelial, connective, muscle and nervous tissue; integument (invertebrate and vertebrate coverings, human skin strata, glands, hair, nails, burns); nervous system (organization types across animals, evolutionary trends, brain regions, meninges, spinal cord, PNS divisions); digestive system (processes, hormones, organs, gut-wall layers); respiratory system (gills, tracheae, lungs, conducting vs respiratory zone, airway structures and their tissues, breathing mechanics). Each topic goes what → how → why, with check-yourself questions. Includes a "slide vs textbook" table and 3D models (epithelia, skin block, gut wall, osteon, three muscle types, neuron).
- **Atlas**: every tissue with micrographs from the lab handout and lectures, a drawn view with optional labels, ID clues, function, location, and a hide-names self-test mode.
- **Remember**: mnemonics, labeled diagrams, commonly confused pairs, flashcard decks (including micrograph → tissue), one-page cheat sheet.
- **Quiz**: 330+ items (multiple choice, typed identification, image ID, sequence ordering) with filters, a question map, retry-missed mode, and a **timed moving-exam simulator**.

Progress is saved in your browser (localStorage).
